# Έλεγχος ταυτότητας συνεδρίας & κλειδιών πρόσβασης (Passkeys)

Η μονάδα **Έλεγχος ταυτότητας συνεδρίας & κλειδιών πρόσβασης** επαληθεύει αιτήματα προγράμματος περιήγησης, κλειδιά Passkey/FIDO2, προαιρετικό εταιρικό OpenID Connect (OIDC) SSO, επαληθευμένες σήραγγες Zero Trust και διακριτικά ομοσπονδίας μέσω μόνιμων συνεδριών στον διακομιστή (`OSCAR_SESSION`).

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Διατήρηση σύνδεσης (Όριο `0`)** | Ο ορισμός των **Όριο αδράνειας** και **Μέγιστη διάρκεια** σε `0` διατηρεί τους σταθμούς συνδεδεμένους μετά από επανεκκίνηση περιηγητή, διακομιστή ή `oscar upgrade` έως την **Αποσύνδεση** ή την απενεργοποίηση λογαριασμού. |
| **Κλειδιά πρόσβασης (Passkeys / FIDO2)** | Ανθεκτική στο ηλεκτρονικό ψάρεμα σύνδεση με Windows Hello, Touch ID, Face ID ή κλειδιά ασφαλείας USB/NFC (YubiKey) — λειτουργεί 100% εκτός σύνδεσης σε απομονωμένα δίκτυα LAN. |
| **Μαζικές προσκλήσεις QR (`/login/enroll?token=oscar_inv_...`)** | Σύνδεσμοι και κωδικοί QR μίας χρήσης από τη σελίδα **Χρήστες & πρόσβαση -> Χρήστες & ρόλοι -> Μαζική εγγραφή (CSV / Επικόλληση)** για άμεση ενεργοποίηση Passkey ή κωδικού. |
| **Ανεξαρτησία κωδικών OSCAR και σήραγγας Octelium** | Οι τοπικοί κωδικοί/Passkeys του OSCAR και τα διαπιστευτήρια της σήραγγας Octelium Zero-Trust είναι ανεξάρτητα επίπεδα (`oscar-tunnel-1` χρησιμοποιεί διακριτικό υπηρεσίας). Η αλλαγή του κωδικού OSCAR **δεν** απαιτεί αλλαγή του κωδικού Octelium. |
| **Τοπική εφεδρεία + Εταιρικό OIDC SSO** | Επιτρέπει σύνδεση με Okta, Microsoft Entra ID, Keycloak ή τον αυτοφιλοξενούμενο κόμβο [`ORNL/oscar-federation-hub`](https://github.com/ORNL/oscar-federation-hub) (Octelium + Authentik) διατηρώντας ενεργούς τους τοπικούς κωδικούς PBKDF2 και τα Passkeys για διακοπές WAN και χώρους χωρίς κινητά τηλέφωνα. |
| **Διακριτικά ομοσπονδίας (`oscar_fed_...`)** | Ανακλητά διακριτικά (`Viewer` ή `Operator`): **(1)** δημιουργήστε τα στον απομακρυσμένο κόμβο στη σελίδα **Χρήστες & πρόσβαση (`/users`) -> Διακριτικά ομοσπονδίας** και **(2)** επικολλήστε τα στον κόμβο εποπτείας στους **Διακομιστές (`/servers`) -> Προσθήκη διακομιστή -> Διακριτικό υπηρεσίας ομοσπονδίας**. |

## Αναφορά ρυθμίσεων

- **Όνομα cookie συνεδρίας (`OSCAR_SESSION`)**: Το όνομα του αδιαφανούς cookie συνεδρίας.
- **Όριο αδράνειας / Μέγιστη διάρκεια (s)**: `0` (προεπιλογή) για παραμονή σε σύνδεση έως τη ρητή αποσύνδεση.
- **Διατήρηση συνεδριών σε επανεκκινήσεις**: Αποθηκεύει συνόψεις `SHA-256` στο `.moduledata/oscar-identity.json` (`0600`).
- **Τομέας WebAuthn (RP ID)**: Προαιρετικός τομέας για Passkeys (κενό χρησιμοποιεί το ενεργό όνομα HTTPS, π.χ. `oscar.local`).
- **Εταιρικό OIDC SSO / Έμπιστη σήραγγα**: Προαιρετικές ρυθμίσεις OpenID Connect (προαιρετικό πιστοποιητικό CA PEM και συντόμευση εξωτερικής κονσόλας χρηστών στο `/users`) και επαληθευμένων κεφαλίδων Octelium (`X-Octelium-User`, `X-Octelium-Groups` και `X-Oscar-Tunnel-Secret`).
