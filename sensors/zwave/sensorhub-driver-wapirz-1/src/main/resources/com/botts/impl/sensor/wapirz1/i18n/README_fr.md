# Détecteur de mouvement WAPIRZ-1

Ce pilote publie les données de mouvement et de température d'un capteur Z-Wave WAPIRZ-1.

## Configuration

- Saisissez un numéro de série unique, sélectionnez le fournisseur de communication Z-Wave et définissez la position du capteur.
- Définissez l'ID du nœud et l'ID du contrôleur sur les valeurs attribuées par le réseau Z-Wave.
- Activez **Réinitialiser le nœud** uniquement lors de la première exécution après l'inclusion du périphérique.
- Définissez **Délai de redéclenchement** sur le nombre de minutes avant qu'un mouvement puisse déclencher à nouveau le capteur.
- Définissez l'intervalle de réveil sur au moins 600 secondes.
