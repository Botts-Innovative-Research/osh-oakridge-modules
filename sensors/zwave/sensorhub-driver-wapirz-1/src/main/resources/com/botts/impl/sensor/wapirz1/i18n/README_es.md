# Detector de movimiento WAPIRZ-1

Este controlador publica datos de movimiento y temperatura de un sensor Z-Wave WAPIRZ-1.

## Configuración

- Introduzca un número de serie único, seleccione el proveedor de comunicación Z-Wave y establezca la posición del sensor.
- Establezca el ID de nodo y el ID del controlador en los valores asignados por la red Z-Wave.
- Active **Reinicializar nodo** solo durante la primera ejecución después de incluir el dispositivo.
- Establezca **Retraso de reactivación** en los minutos que deben transcurrir antes de que el movimiento vuelva a activar el sensor.
- Establezca el intervalo de activación en al menos 600 segundos.
