# Multisensor ZW100 6

Este controlador Z-Wave supervisa movimiento, temperatura, humedad, índice ultravioleta, luminancia, vibración y estado de batería.

## Configuración

- Introduzca un número de serie único, la posición y el UID del tipo de dispositivo de OpenHAB.
- Establezca el ID de nodo y el ID del controlador asignados por la red Z-Wave.
- Configure los intervalos de activación y de informe; el funcionamiento con batería necesita un intervalo de informe de al menos 240 segundos.
- Seleccione el comando de movimiento, la sensibilidad y el tiempo de restablecimiento.
- Seleccione la unidad de temperatura y configure los umbrales de temperatura, humedad, luminancia, batería y UV.
- Active los informes selectivos para publicar mediciones solo al alcanzar un umbral.
