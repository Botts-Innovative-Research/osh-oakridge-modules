# ZW100 MultiSensor 6

This Z-Wave driver monitors motion, temperature, humidity, ultraviolet index, luminance, vibration, and battery state.

## Configuration

- Enter a unique serial number, position, and the OpenHAB thing-type UID.
- Set the node ID and controller ID assigned by the Z-Wave network.
- Configure the wake-up and sensor-report intervals; battery operation requires a report interval of at least 240 seconds.
- Select the motion command, sensitivity, and reset timeout.
- Select the temperature unit and configure temperature, humidity, luminance, battery, and UV reporting thresholds.
- Enable selective reporting to publish measurements only when a threshold is reached.
