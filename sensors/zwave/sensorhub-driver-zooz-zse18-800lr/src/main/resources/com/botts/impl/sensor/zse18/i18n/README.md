# Zooz ZSE18-800LR Motion Detector

This driver publishes motion, vibration, and battery information from a long-range Z-Wave sensor.

## Configuration

- Enter a unique serial number, select the Z-Wave communication provider, and set the sensor position.
- Set the node ID and controller ID assigned by the Z-Wave network.
- Enable **Reinitialize Node** only for the first run after including the device.
- Configure PIR sensitivity, vibration sensing, trigger interval, report type, LED behavior, and the low-battery threshold.
- Lock advanced settings only after confirming their values.
- Use a wake-up interval of at least 600 seconds; shorter reporting intervals reduce battery life.
