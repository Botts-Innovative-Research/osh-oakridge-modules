# Détecteur de mouvement Zooz ZSE18-800LR

Ce pilote publie les informations de mouvement, de vibrations et de batterie d'un capteur Z-Wave longue portée.

## Configuration

- Saisissez un numéro de série unique, sélectionnez le fournisseur de communication Z-Wave et définissez la position du capteur.
- Définissez l'ID du nœud et l'ID du contrôleur attribués par le réseau Z-Wave.
- Activez **Réinitialiser le nœud** uniquement lors de la première exécution après l'inclusion du périphérique.
- Configurez la sensibilité PIR, le capteur de vibrations, l'intervalle de déclenchement, le type de rapport, le voyant DEL et le seuil de batterie faible.
- Verrouillez les paramètres avancés uniquement après avoir vérifié leurs valeurs.
- Utilisez un intervalle de réveil d'au moins 600 secondes ; des intervalles de rapport plus courts réduisent l'autonomie.
