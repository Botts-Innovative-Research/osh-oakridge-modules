# Detector de movimiento Zooz ZSE18-800LR

Este controlador publica información de movimiento, vibración y batería de un sensor Z-Wave de largo alcance.

## Configuración

- Introduzca un número de serie único, seleccione el proveedor de comunicación Z-Wave y establezca la posición del sensor.
- Establezca el ID de nodo y el ID del controlador asignados por la red Z-Wave.
- Active **Reinicializar nodo** solo durante la primera ejecución después de incluir el dispositivo.
- Configure la sensibilidad PIR, el sensor de vibración, el intervalo de activación, el tipo de informe, el indicador LED y el umbral de batería baja.
- Bloquee la configuración avanzada solo después de comprobar sus valores.
- Use un intervalo de activación de al menos 600 segundos; los intervalos de informe más cortos reducen la duración de la batería.
