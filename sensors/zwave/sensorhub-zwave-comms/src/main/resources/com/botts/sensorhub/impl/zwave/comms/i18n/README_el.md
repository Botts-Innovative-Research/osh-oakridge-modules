# Υπηρεσία επικοινωνίας Z-Wave

Αυτή η υπηρεσία διαχειρίζεται τη σειριακή σύνδεση με έναν ελεγκτή Z-Wave και κοινοποιεί τους εντοπισμένους κόμβους στα προγράμματα οδήγησης αισθητήρων.

## Διαμόρφωση

- Επιλέξτε τη σειριακή θύρα USB που είναι συνδεδεμένη στον ελεγκτή.
- Ορίστε τον ρυθμό baud του ελεγκτή· η προεπιλογή είναι 115200.
- Ενεργοποιήστε τον **Κύριο ελεγκτή** όταν αυτή η συσκευή είναι ο κύριος ελεγκτής Z-Wave.
- Εισαγάγετε το αναγνωριστικό του ελεγκτή και τη φυσική του θέση.
- Τα **Εγγεγραμμένα προγράμματα οδήγησης αισθητήρων** εμφανίζουν τους κόμβους Z-Wave που είναι συσχετισμένοι επί του παρόντος με την υπηρεσία.
- Εκκινήστε αυτήν την υπηρεσία πριν εκκινήσετε τα προγράμματα οδήγησης αισθητήρων που εξαρτώνται από αυτήν.
