# Sensor de puerta/ventana WADWAZ-1

Este controlador publica el estado abierto/cerrado de un sensor Z-Wave WADWAZ-1.

## Configuración

- Introduzca un número de serie único y la posición del sensor.
- Establezca el ID de nodo y el ID del controlador en los valores asignados por la red Z-Wave.
- Active **Reinicializar nodo** solo durante la primera ejecución después de incluir el dispositivo.
- Establezca el intervalo de activación en al menos 600 segundos, utilizando incrementos de 200 segundos.
- Active **Inicio automático** para comenzar la supervisión al iniciar el nodo.
