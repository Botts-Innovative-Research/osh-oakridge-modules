# WADWAZ-1 Window/Door Sensor

This driver publishes open/closed state from a WADWAZ-1 Z-Wave sensor.

## Configuration

- Enter a unique serial number and the sensor position.
- Set the node ID and controller ID to the values assigned by the Z-Wave network.
- Enable **Reinitialize Node** only for the first run after including the device.
- Set the wake-up interval to at least 600 seconds, using increments of 200 seconds.
- Enable **Auto Start** to start monitoring when the node starts.
