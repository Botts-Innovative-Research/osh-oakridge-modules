# HomeSeer DS100 G8 Window/Door Sensor

This driver publishes open/closed and battery information from a DS100 Z-Wave sensor.

## Configuration

- Enter a unique serial number and the sensor position.
- Select the Z-Wave communication provider used by the sensor.
- Set the node ID and controller ID to the values assigned by the Z-Wave network.
- Enable **Reinitialize Node** only for the first run after including the device.
- Configure Basic Set reporting, reversed report values, the low-battery threshold, and the wake-up interval as required.
- The wake-up interval must be at least 600 seconds.
