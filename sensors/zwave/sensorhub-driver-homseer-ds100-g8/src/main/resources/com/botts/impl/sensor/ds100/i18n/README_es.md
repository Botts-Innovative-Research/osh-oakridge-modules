# Sensor de puerta/ventana HomeSeer DS100 G8

Este controlador publica el estado abierto/cerrado y la información de batería de un sensor Z-Wave DS100.

## Configuración

- Introduzca un número de serie único y la posición del sensor.
- Seleccione el proveedor de comunicación Z-Wave utilizado por el sensor.
- Establezca el ID de nodo y el ID del controlador en los valores asignados por la red Z-Wave.
- Active **Reinicializar nodo** solo durante la primera ejecución después de incluir el dispositivo.
- Configure los informes Basic Set, la inversión de valores, el umbral de batería baja y el intervalo de activación según sea necesario.
- El intervalo de activación debe ser de al menos 600 segundos.
