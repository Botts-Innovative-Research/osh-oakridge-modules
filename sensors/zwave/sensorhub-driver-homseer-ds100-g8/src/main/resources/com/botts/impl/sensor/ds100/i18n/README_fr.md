# Capteur de porte/fenêtre HomeSeer DS100 G8

Ce pilote publie l'état ouvert/fermé et les informations de batterie d'un capteur Z-Wave DS100.

## Configuration

- Saisissez un numéro de série unique et la position du capteur.
- Sélectionnez le fournisseur de communication Z-Wave utilisé par le capteur.
- Définissez l'ID du nœud et l'ID du contrôleur sur les valeurs attribuées par le réseau Z-Wave.
- Activez **Réinitialiser le nœud** uniquement lors de la première exécution après l'inclusion du périphérique.
- Configurez les rapports Basic Set, l'inversion des valeurs, le seuil de batterie faible et l'intervalle de réveil selon les besoins.
- L'intervalle de réveil doit être d'au moins 600 secondes.
