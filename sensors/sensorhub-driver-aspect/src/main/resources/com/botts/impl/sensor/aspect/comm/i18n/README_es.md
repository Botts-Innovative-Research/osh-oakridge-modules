# Controlador de comunicación Modbus TCP

Este proveedor conecta un sensor con un dispositivo Modbus TCP/IP.

## Configuración

- **Host remoto:** dirección IP o nombre DNS del dispositivo.
- **Puerto remoto:** puerto TCP del dispositivo; Modbus suele utilizar el puerto 502.
- **Intervalo de direcciones:** primera y última dirección Modbus que se explorarán.
- **Opciones de conexión:** tiempo de espera, período de reconexión, máximo de intentos y comprobación opcional de accesibilidad.
