# Pilote de communication Modbus TCP

Ce fournisseur connecte un capteur à un périphérique Modbus TCP/IP.

## Configuration

- **Hôte distant :** adresse IP ou nom DNS du périphérique.
- **Port distant :** port TCP du périphérique ; Modbus utilise généralement le port 502.
- **Plage d'adresses :** première et dernière adresses Modbus à analyser.
- **Options de connexion :** délai, période de reconnexion, nombre maximal de tentatives et vérification facultative de l'accessibilité.
