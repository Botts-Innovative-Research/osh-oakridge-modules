# Πρόγραμμα οδήγησης επικοινωνίας Modbus TCP

Αυτός ο πάροχος συνδέει έναν αισθητήρα με μια συσκευή Modbus TCP/IP.

## Διαμόρφωση

- **Απομακρυσμένος κεντρικός υπολογιστής:** Διεύθυνση IP ή όνομα DNS της συσκευής.
- **Απομακρυσμένη θύρα:** Θύρα TCP της συσκευής· το Modbus χρησιμοποιεί συνήθως τη θύρα 502.
- **Εύρος διευθύνσεων:** Πρώτη και τελευταία διεύθυνση Modbus προς σάρωση.
- **Επιλογές σύνδεσης:** Χρονικό όριο, περίοδος επανασύνδεσης, μέγιστος αριθμός προσπαθειών και προαιρετικός έλεγχος προσβασιμότητας.
