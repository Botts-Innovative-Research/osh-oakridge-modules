# Αισθητήρας ακτινοβολίας Kromek D3S

Αυτό το πρόγραμμα οδήγησης διαβάζει δεδομένα ακτινοβολίας που εξάγονται από έναν αισθητήρα Kromek D3S.

## Διαμόρφωση

- Εισαγάγετε έναν μοναδικό σειριακό αριθμό για τον αισθητήρα.
- Ορίστε τον **Φάκελο δεδομένων** στην απόλυτη διαδρομή που περιέχει τα αρχεία δεδομένων D3S.
- Επιβεβαιώστε ότι η διεργασία OpenSensorHub μπορεί να διαβάσει τον φάκελο.
- Ενεργοποιήστε την **Αυτόματη εκκίνηση** για φόρτωση των δεδομένων αισθητήρα κατά την εκκίνηση του κόμβου.
