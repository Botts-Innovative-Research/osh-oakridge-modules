# Capteur de rayonnement Kromek D3S

Ce pilote lit les données de rayonnement exportées par un capteur Kromek D3S.

## Configuration

- Saisissez un numéro de série unique pour le capteur.
- Définissez **Dossier de données** sur le chemin absolu contenant les fichiers de données du D3S.
- Vérifiez que le processus OpenSensorHub peut lire le dossier.
- Activez **Démarrage automatique** pour charger les données du capteur au démarrage du nœud.
