# Sensor de radiación Kromek D3S

Este controlador lee los datos de radiación exportados por un sensor Kromek D3S.

## Configuración

- Introduzca un número de serie único para el sensor.
- Establezca **Carpeta de datos** en la ruta absoluta que contiene los archivos de datos del D3S.
- Compruebe que el proceso de OpenSensorHub pueda leer la carpeta.
- Active **Inicio automático** para cargar los datos del sensor al iniciar el nodo.
