# Σύστημα αισθητήρων λωρίδας

Το Σύστημα λωρίδας δημιουργεί ένα γονικό σύστημα για μία πύλη ανίχνευσης ακτινοβολίας (RPM) και μία ή περισσότερες κάμερες λωρίδας.

## Γενική διαμόρφωση

- Δώστε στη λωρίδα ένα μοναδικό όνομα μονάδας και μοναδικό αναγνωριστικό.
- Εισαγάγετε το σταθερό γεωγραφικό πλάτος και μήκος της, όταν είναι γνωστά.
- Ενεργοποιήστε τη **Διαγραφή δεδομένων κατά την κατάργηση λωρίδας** μόνο όταν η κατάργηση μιας λωρίδας πρέπει επίσης να διαγράφει τις αποθηκευμένες εγγραφές της.

## Επιλογές λωρίδας

- Στην **Αρχική διαμόρφωση RPM**, επιλέξτε Aspect, Rapiscan ή RS-350 και εισαγάγετε τον κεντρικό υπολογιστή και τη θύρα της συσκευής. Το Aspect απαιτεί επίσης εύρος διευθύνσεων Modbus.
- Στην **Αρχική διαμόρφωση κάμερας**, προσθέστε κάθε κάμερα Sony, Axis ή Προσαρμοσμένη και εισαγάγετε τον κεντρικό υπολογιστή, το όνομα χρήστη και τον κωδικό πρόσβασης όταν απαιτούνται.
- Για κάμερες Axis, επιλέξτε τον κωδικοποιητή ροής. Για Προσαρμοσμένες κάμερες, εισαγάγετε τη διαδρομή μετά τον κεντρικό υπολογιστή και τη θύρα της κάμερας.
- Ελέγξτε όλες τις δημιουργημένες θυγατρικές μονάδες πριν αποθηκεύσετε τη λωρίδα.
