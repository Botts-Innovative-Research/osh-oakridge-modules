# Πρόγραμμα οδήγησης βίντεο FFmpeg

Αυτό το πρόγραμμα οδήγησης δημοσιεύει βίντεο από αρχείο ή από ροή δικτύου συμβατή με FFmpeg.

## Σύνδεση

- Ορίστε τη **Διαδρομή αρχείου** για εγγεγραμμένο βίντεο ή τη **Συμβολοσειρά σύνδεσης** για ζωντανή ροή.
- Για αναπαραγωγή αρχείου, ορίστε τον ρυθμό καρέ, το μέγεθος ενδιάμεσης μνήμης και την προαιρετική συμπεριφορά επανάληψης.
- Για ροή δικτύου, επιλέξτε TCP όταν απαιτείται· διαφορετικά το πρόγραμμα οδήγησης χρησιμοποιεί UDP.
- Ενεργοποιήστε την **Παράβλεψη χρονικών σημάνσεων δεδομένων** όταν η πηγή δεν διαθέτει χρησιμοποιήσιμες χρονικές σημάνσεις.

## Έξοδοι

- Ενεργοποιήστε το **HLS** για δημοσίευση εξόδου διαδρομής αρχείου HLS.
- Ενεργοποιήστε τα **Καρέ βίντεο** για δημοσίευση δυαδικών καρέ βίντεο.
- Ορίστε το αναγνωριστικό ροής, τη θέση πηγής, το χρονικό όριο σύνδεσης και τη συμπεριφορά επανασύνδεσης όπως απαιτείται.
