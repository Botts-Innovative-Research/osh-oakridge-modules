# TSTAR API Driver

This driver retrieves sensor data from the TSTAR HTTP API.

## Configuration

- Enter a unique serial number for this driver instance.
- Under **HTTP**, enter the remote host, port, optional resource path, and TLS setting.
- Enter the TSTAR username and password.
- Enter the campaign ID that the driver should access.
- Configure connection and reconnection values when the API requires longer timeouts.
- Enable **Auto Start** to connect when the OpenSensorHub node starts.
