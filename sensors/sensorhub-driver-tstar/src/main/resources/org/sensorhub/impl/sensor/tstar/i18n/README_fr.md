# Pilote d'API TSTAR

Ce pilote récupère les données des capteurs depuis l'API HTTP TSTAR.

## Configuration

- Saisissez un numéro de série unique pour cette instance du pilote.
- Dans **HTTP**, saisissez l'hôte distant, le port, le chemin facultatif de la ressource et le paramètre TLS.
- Saisissez le nom d'utilisateur et le mot de passe TSTAR.
- Saisissez l'ID de la campagne à laquelle le pilote doit accéder.
- Configurez les valeurs de connexion et de reconnexion lorsque l'API nécessite des délais plus longs.
- Activez **Démarrage automatique** pour établir la connexion au démarrage du nœud OpenSensorHub.
