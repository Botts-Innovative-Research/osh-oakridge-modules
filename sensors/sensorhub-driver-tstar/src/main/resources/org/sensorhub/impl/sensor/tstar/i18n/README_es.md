# Controlador de API TSTAR

Este controlador obtiene datos de sensores desde la API HTTP de TSTAR.

## Configuración

- Introduzca un número de serie único para esta instancia del controlador.
- En **HTTP**, introduzca el host remoto, el puerto, la ruta opcional del recurso y la configuración TLS.
- Introduzca el nombre de usuario y la contraseña de TSTAR.
- Introduzca el ID de la campaña a la que debe acceder el controlador.
- Configure los valores de conexión y reconexión cuando la API necesite tiempos de espera más largos.
- Active **Inicio automático** para conectarse al iniciar el nodo OpenSensorHub.
