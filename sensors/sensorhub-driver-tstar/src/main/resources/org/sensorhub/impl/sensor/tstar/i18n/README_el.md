# Πρόγραμμα οδήγησης API TSTAR

Αυτό το πρόγραμμα οδήγησης ανακτά δεδομένα αισθητήρων από το API HTTP του TSTAR.

## Διαμόρφωση

- Εισαγάγετε έναν μοναδικό σειριακό αριθμό για αυτήν την παρουσία του προγράμματος οδήγησης.
- Στην ενότητα **HTTP**, εισαγάγετε τον απομακρυσμένο κεντρικό υπολογιστή, τη θύρα, την προαιρετική διαδρομή πόρου και τη ρύθμιση TLS.
- Εισαγάγετε το όνομα χρήστη και τον κωδικό πρόσβασης TSTAR.
- Εισαγάγετε το αναγνωριστικό εκστρατείας στο οποίο πρέπει να έχει πρόσβαση το πρόγραμμα οδήγησης.
- Διαμορφώστε τις τιμές σύνδεσης και επανασύνδεσης όταν το API απαιτεί μεγαλύτερα χρονικά όρια.
- Ενεργοποιήστε την **Αυτόματη εκκίνηση** για σύνδεση κατά την εκκίνηση του κόμβου OpenSensorHub.
