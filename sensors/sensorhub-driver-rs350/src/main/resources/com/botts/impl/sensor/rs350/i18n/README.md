# RS-350 Radiation Sensor

This driver connects an RS-350 radiation detector to OpenSensorHub.

## Configuration

- Enter the detector serial number.
- Under **Communication Settings**, add a TCP provider and enter the RS-350 host and port.
- Configure connection timeout, reconnection, and reachability settings as needed.
- Under **Outputs**, enable status, background spectrum, foreground spectrum, and alarm data as required.
- Enable **Auto Start** to start the driver with the node.
