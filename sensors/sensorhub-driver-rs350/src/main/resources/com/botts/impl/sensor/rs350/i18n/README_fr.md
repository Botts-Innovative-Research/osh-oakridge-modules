# Capteur de rayonnement RS-350

Ce pilote connecte un détecteur de rayonnement RS-350 à OpenSensorHub.

## Configuration

- Saisissez le numéro de série du détecteur.
- Dans **Paramètres de communication**, ajoutez un fournisseur TCP et saisissez l'hôte et le port du RS-350.
- Configurez le délai, la reconnexion et la vérification d'accessibilité selon les besoins.
- Dans **Sorties**, activez les données d'état, de spectre de fond, de spectre de premier plan et d'alarme nécessaires.
- Activez **Démarrage automatique** pour démarrer le pilote avec le nœud.
