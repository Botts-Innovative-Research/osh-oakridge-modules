# Sensor de radiación RS-350

Este controlador conecta un detector de radiación RS-350 con OpenSensorHub.

## Configuración

- Introduzca el número de serie del detector.
- En **Configuración de comunicación**, añada un proveedor TCP e introduzca el host y el puerto del RS-350.
- Configure el tiempo de espera, la reconexión y la comprobación de accesibilidad según sea necesario.
- En **Salidas**, active los datos de estado, espectro de fondo, espectro de primer plano y alarma que necesite.
- Active **Inicio automático** para iniciar el controlador con el nodo.
