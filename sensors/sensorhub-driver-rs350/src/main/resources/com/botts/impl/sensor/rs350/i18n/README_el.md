# Αισθητήρας ακτινοβολίας RS-350

Αυτό το πρόγραμμα οδήγησης συνδέει έναν ανιχνευτή ακτινοβολίας RS-350 στο OpenSensorHub.

## Διαμόρφωση

- Εισαγάγετε τον σειριακό αριθμό του ανιχνευτή.
- Στις **Ρυθμίσεις επικοινωνίας**, προσθέστε έναν πάροχο TCP και εισαγάγετε τον κεντρικό υπολογιστή και τη θύρα του RS-350.
- Διαμορφώστε το χρονικό όριο σύνδεσης, την επανασύνδεση και τις ρυθμίσεις προσβασιμότητας όπως απαιτείται.
- Στις **Εξόδους**, ενεργοποιήστε την κατάσταση, το φάσμα υποβάθρου, το φάσμα προσκηνίου και τα δεδομένα συναγερμού όπως απαιτείται.
- Ενεργοποιήστε την **Αυτόματη εκκίνηση** ώστε το πρόγραμμα οδήγησης να εκκινείται μαζί με τον κόμβο.
