# Αισθητήρας ακτινοβολίας Kromek D5

Αυτό το πρόγραμμα οδήγησης συνδέει έναν αισθητήρα ακτινοβολίας Kromek D5 και δημοσιεύει τις επιλεγμένες αναφορές της συσκευής.

## Διαμόρφωση

- Εισαγάγετε έναν μοναδικό σειριακό αριθμό.
- Προσθέστε τον πάροχο επικοινωνίας που χρησιμοποιείται για πρόσβαση στη ροή δεδομένων του D5.
- Στις **Εξόδους**, ενεργοποιήστε μόνο τις αναφορές που απαιτούνται από την εγκατάστασή σας.
- Οι αναφορές ραδιομετρικών δεδομένων και ραδιομετρικής κατάστασης είναι ενεργοποιημένες από προεπιλογή· οι προαιρετικές αναφορές κατάστασης, δόσης, ισοτόπων, ορίων και πληροφοριών συσκευής μπορούν να ενεργοποιηθούν ξεχωριστά.
- Ενεργοποιήστε την **Αυτόματη εκκίνηση** ώστε το πρόγραμμα οδήγησης να εκκινείται μαζί με τον κόμβο OpenSensorHub.
