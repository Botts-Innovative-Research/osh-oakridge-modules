# Sensor de radiación Kromek D5

Este controlador conecta un sensor de radiación Kromek D5 y publica los informes seleccionados del dispositivo.

## Configuración

- Introduzca un número de serie único.
- Añada el proveedor de comunicación utilizado para acceder al flujo de datos del D5.
- En **Salidas**, active solo los informes necesarios para su instalación.
- Los informes de radiometría y estado radiométrico están activos de forma predeterminada; los informes opcionales de estado, dosis, isótopos, umbrales e información del dispositivo se activan por separado.
- Active **Inicio automático** para iniciar el controlador con el nodo OpenSensorHub.
