# Capteur de rayonnement Kromek D5

Ce pilote connecte un capteur de rayonnement Kromek D5 et publie les rapports sélectionnés du périphérique.

## Configuration

- Saisissez un numéro de série unique.
- Ajoutez le fournisseur de communication utilisé pour atteindre le flux de données du D5.
- Dans **Sorties**, activez uniquement les rapports nécessaires à votre déploiement.
- Les rapports de radiométrie et d'état radiométrique sont activés par défaut ; les rapports facultatifs d'état, de dose, d'isotopes, de seuils et d'informations du périphérique peuvent être activés séparément.
- Activez **Démarrage automatique** pour démarrer le pilote avec le nœud OpenSensorHub.
