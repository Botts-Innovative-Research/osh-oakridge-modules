# Επαγωγικός διακόπτης προσέγγισης

Αυτό το πρόγραμμα οδήγησης Raspberry Pi παρακολουθεί έναν επαγωγικό διακόπτη προσέγγισης μέσω εισόδων GPIO.

## Καλωδίωση και διαμόρφωση

- Εισαγάγετε έναν μοναδικό σειριακό αριθμό για τον διακόπτη.
- Ορίστε τον **Ακροδέκτη κανονικά κλειστής επαφής** στο GPIO που συνδέεται στη λευκή επαφή NC, όταν είναι καλωδιωμένη.
- Ορίστε τον **Ακροδέκτη κανονικά ανοικτής επαφής** στο GPIO που συνδέεται στη μαύρη επαφή NO, όταν είναι καλωδιωμένη.
- Επιλέξτε **Δεν έχει οριστεί** για επαφή που δεν είναι συνδεδεμένη. Μπορεί να χρησιμοποιηθεί οποιαδήποτε από τις δύο επαφές ή και οι δύο.
- Επαληθεύστε την αρίθμηση GPIO και την ηλεκτρική συμβατότητα πριν εκκινήσετε το πρόγραμμα οδήγησης.
- Ενεργοποιήστε την **Αυτόματη εκκίνηση** για παρακολούθηση του διακόπτη κατά την εκκίνηση του κόμβου.
